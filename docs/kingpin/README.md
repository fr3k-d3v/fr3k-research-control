## Reading conventions
- **VERIFIED** = read live from GitHub or Fleet on 28 Nov 2026, or recorded with a job or commit ID.
- **REPORTED** = taken from the owner's instructions or earlier agent notes; not re-checked in this pass.
- **UNVERIFIED** = could not be confirmed; do not rely on it without checking.
- A commit is not a deployment, a heartbeat is not progress, and a simulation is not hardware verification.

## What is deliberately not in this folder
No credentials, tokens, SMTP values, API keys, IP addresses, tailnet names, hostnames, private client or personal contact details, model assets, or chat transcripts. If something needed is missing, it lives on the authorised machine or in the owner's accounts, not here.
